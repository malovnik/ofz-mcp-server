# Размещение MCP MOEX

Целевой сервер — dovod-public, тот же Sprintbox, где club.nikexpert.ru.
Адрес подключения: https://club.nikexpert.ru/mcp/moex/mcp (Streamable HTTP).
Ключи и платная модель не нужны: сервер читает MOEX ISS напрямую.

Код с зависимостями поставляется архивом из проверенного коммита.
Релизы — `/srv/ofz-mcp/releases/<commit>`, текущий — симлинк `/srv/ofz-mcp/current`.
Node.js22 уже установлен: `/opt/node22/bin/node`. Служба `ofz-mcp.service`
работает от отдельного пользователя ofzmcp, слушает только 127.0.0.1:8371.
Nginx передаёт исключительно `/mcp/moex/`, сохраняет TLS сайта и ограничивает
нагрузку. Данные кэшируются минуту; после пяти минут без обновления запрос
заканчивается ошибкой. Health считает кэш старше минуты деградацией.
Таймер `ofz-mcp-health.timer` пишет результат проверки в journal каждые 2мин.

Пять ответов перед выкладкой:

1. Риск для соседей — ошибочная конфигурация nginx и расход памяти. Изолированный
   префикс, `nginx -t` до reload, служба ограничена 256MiB/50%CPU, контроль клуба до/после.
2. Откат новой установки — остановить ofz-mcp и его таймер, убрать единственный
   include из club-site.conf, проверить nginx и reload. Резервная копия исходного
   конфига находится в `/srv/ofz-mcp/rollback/club-site.conf.before`.
   Для следующего релиза вернуть current к предыдущему каталогу и restart службы.
3. Отказ виден в `/mcp/moex/health`, journal служб ofz-mcp/ofz-mcp-health,
   `/var/log/nginx/ofz-mcp-access.log`; ротация наследует `/var/log/nginx/*.log`.
4. Секретов нет. Сервер не получает ключей школы, сайта или брокера.
5. Служба новая; сайт продолжает работать. Reload nginx не обрывает текущие
   соединения. При отказе конфигурации прежний nginx остаётся запущен.

Проверка после выкладки: SDK-клиент выполняет initialize, tools/list и вызывает
все три инструмента; get_bonds возвращает тикеры и время чтения MOEX. Проверяются
неверный Origin (403), неправильные параметры, свежий health, автозапуск и restart.
Неисправный Railway-адрес не переиспользуется. В уроке 346849202 меняется только
текст и href одной ссылки в дополнительных материалах.

Первичные спецификации: https://modelcontextprotocol.io/specification/2025-11-25/basic/transports
и https://iss.moex.com/iss/reference/ .
